# Homebrew Tap

Homebrew casks maintained by pers0n4.

## Casks

### [Deltavee](https://github.com/pers0n4/deltavee)

A macOS menu bar app for tracking Claude and Codex subscription usage. Requires Apple silicon and macOS 26 or later.

If you installed Deltavee manually, quit it and remove the old `Deltavee.app` before installing with Homebrew; keep its Application Support folder to preserve your settings and usage history.

```sh
brew install --cask pers0n4/tap/deltavee
```

See the Deltavee documentation for [updates](https://github.com/pers0n4/deltavee#homebrew-apple-silicon) and [uninstallation](https://github.com/pers0n4/deltavee#uninstall).
